# Встроенная озвучка BookMT

Русский язык, женский F1 и мужской M1. Supertonic 3 INT8 через sherpa-onnx 1.13.8
(ONNX Runtime 1.28.2), CPU, 2 потока, 8 шагов синтеза, 44,1 кГц. Обе голосовые
характеристики используют одну модель; в настройках доступны два голоса.
Системный Android TTS не используется. APK содержит все необходимые файлы,
без загрузок при установке или первом запуске. Разрешения INTERNET нет.

## Использование

В настройках чтения выбрать голос и скорость 0,75–1,5×. Кнопка воспроизведения
внизу читалки начинает озвучку с текущей позиции. Первый запуск показывает
локальный текст условий модели OpenRAIL-M. Настройки сохраняются в DataStore;
смена голоса/скорости применяется после остановки и нового запуска.

Пауза, продолжение и остановка доступны в читалке и уведомлении. Озвучка
продолжается при выключенном экране и сворачивании приложения. При выходе
из читалки прекращается. Отключение наушников и потеря аудиофокуса ставят
озвучку на паузу; возобновление выполняет пользователь. После завершения
сессия модели освобождается. В паузе она остаётся в памяти для продолжения.

Текст подаётся лениво по главам, фрагменты ограничены 240 символами с
предпочтением границы предложения. Следующий фрагмент синтезируется во время
воспроизведения текущего; очередь ограничена. Читалка следует за произносимым
фрагментом. После повторного открытия возможно повторение начала фрагмента
или страницы: пагинация сохраняет начало видимой страницы. Это не пословная
синхронизация.

## Сборка

Нужен Python 3.11+. Один раз выполнить `python tools/prepare_tts.py`.
Этот инструмент разработки скачивает только два зафиксированных файла,
проверяет SHA-256 и извлекает строго заданные файлы в `.tts-cache/assets`.
Архивы и модели не коммитятся в Git. Для повторной подготовки из локального
кэша: `python tools/prepare_tts.py --offline`. Gradle сам ничего не скачивает
для TTS; при отсутствии подготовленных моделей сборка завершится ошибкой.

Далее обычная сборка `gradlew.bat :app:assembleDebug --offline` при наличии
остальных зависимостей в Gradle-кэше. Модели читаются из assets APK без
создания второй постоянной копии в filesDir. Поддерживаются ABI AAR:
arm64-v8a, armeabi-v7a, x86, x86_64. 64-битные ELF имеют выравнивание 16 КБ.

Лицензии и notices включены в `app/src/main/assets/licenses`. Условия модели
можно повторно открыть в настройках озвучки. Это лицензия модели с условиями
использования, а не MIT-лицензия кода примеров из архива.

## Границы текущей версии

- TTS доступна для текстовых книг EPUB/FB2/TXT/MD. PDF/OCR не подключены.
- По умолчанию вся книга читается выбранным голосом. Автоматическое
  распределение реплик по персонажам и языкам пока не включено.
- Ударения, имена, сокращения и числа могут произноситься с ошибками;
  словаря произношения пока нет. Скорость и расход батареи зависят от телефона.
- Нет экспорта аудиокниги, таймера сна или импорта сторонних моделей.
- APK существенно больше прежнего: модели и native runtime встроены целиком.

## Проверки

`OfflineTtsTest` запускает настоящую модель из APK для обоих голосов,
проверяет непустой конечный PCM и сохраняет примеры WAV в cacheDir приложения.
Второй сценарий проверяет foreground-сервис, аудиовыход, паузу, продолжение
и остановку. `SpeechBoundaryTest` проверяет ограничение размера фрагмента
и сохранение Unicode/текста. Результаты конкретного запуска приведены ниже.

14 октября 2026: на эмуляторе Android 15 / API 35 x86_64 с отключёнными
Wi-Fi, мобильными данными и включённым авиарежимом прошли оба Android-теста.
Проверен настоящий синтез из assets APK обоими голосами, воспроизведение
после ухода Activity в фон, пауза, продолжение и остановка. Получены WAV
44,1 кГц длиной около 6,1 с: F1 синтезировался за 5,82 с, M1 — за 3,93 с.
Эти времена относятся к эмулятору и не прогнозируют скорость телефона.
24 модульных теста прошли без ошибок. Проверки `aapt2 dump permissions` и
`zipalign -c -P 16 4` подтвердили отсутствие INTERNET и выравнивание APK.
Живое прослушивание на телефоне, длительная работа и произношение на
разных книгах остаются ручной проверкой; качество речи не оценивалось
только по наличию непустого PCM.

Debug и Release (`assembleRelease`, включая R8 и lintVital) собираются
успешно офлайн. Release APK не подписан пользовательским release-ключом;
для установки в этом проходе выдаётся debug APK с прежней debug-подписью.

Добавлена подсветка реально воспроизводимой фразы, дополнительные паузы после
предложений/абзацев и обработка краевой тишины модели. Позиция прослушивания

и сессии. Подробности и текущие результаты: [READER_ENGINE.md](READER_ENGINE.md).
