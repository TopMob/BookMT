# Сохранение позиции и повторное открытие — 18 октября 2026

## Исправления

- Восстановление прокрутки ждёт фактической разметки нужного текста и размещения элемента списка. Раньше `scrollToItem` мог отработать на пустом элементе, потерять смещение внутри страницы и оставить экран в начале при правильной позиции в Room.
- Незагруженные страницы имеют временную высоту. Список больше не пытается заполнить экран множеством элементов нулевой высоты, запуская загрузку текста далеко за видимой областью.
- Расширение временного окна страниц и смена параметров разметки повторно привязывают экран к текстовой позиции. На время восстановления показывается индикатор вместо неправильного участка текста.
- Позиция видимой строки вычисляется по уже отрисованному `TextLayoutResult`. Убраны повторные фоновые измерения текста и задержка определения позиции во время прокрутки.
- Запись позиции запускается с интервалом 250 мс при движении, а также при уходе с экрана и очистке ViewModel. Непрерывная прокрутка больше не откладывает сохранение бесконечно.
- Начавшиеся записи завершаются независимо от отмены экрана и проходят через mutex, чтобы медленная старая запись не перезаписала более новую.
- Новый экран книги ждёт незавершённое сохранение при выходе предыдущего экрана. Быстрое повторное открытие не читает заведомо устаревшую позицию из базы.
- Если финальный callback видимой строки приходит после `ON_PAUSE` или очистки ViewModel, он тоже проходит через очередь сохранения и не теряется в отменённом scope.
- Разметка сохраняется по отдельным блокам книги. Можно выйти до завершения общего счётчика страниц: готовые блоки будут использованы при следующем открытии без повторной пагинации. Полный кэш страниц сохранён; повреждённый кэш пересчитывается.
- Первая публикация текста ждёт пользовательских настроек. Шрифт и стиль переиспользуются между обновлениями позиции вместо повторного создания при каждой рекомпозиции.

## Границы проверки

Телефон не используется по указанию владельца. Изменения проверяются кодом и на эмуляторе Android API 35. Численного сравнения скорости до/после на пользовательском устройстве нет.

Первые расчёты для новой книги или новых параметров шрифта/экрана по-прежнему необходимы. Полный счётчик страниц может завершаться в фоне; уже готовые блоки сохраняются отдельно.

При принудительном завершении процесса или отключении питания до выполнения очередной записи возможна потеря последних ещё не записанных изменений; абсолютная гарантия сохранения каждого кадра не заявляется. Обычный выход и немедленное повторное открытие обрабатываются отдельно.

Схема Room, идентификаторы книг, формат закладок и резервных копий не меняются. Новая информация находится только в удаляемом локальном кэше разметки. Сеть не используется.
